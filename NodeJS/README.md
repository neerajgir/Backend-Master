## 🎯 Kaise Use Karein

Har folder mein apna `README.md` hai jisme:
- **Intro** — topic ka overview
- **Explanation** — code snippets ke saath detail

## Summary

Node.js ek **JavaScript runtime** hai jo server-side code chalata hai. Is series mein tumne seekha:
1. Files read/write karna (sync vs async)
2. HTTP server banana
3. Event-driven programming
4. Streams se bade files handle karna
5. Crypto aur OS-level info lena

Agle steps: Express.js, databases (MongoDB/PostgreSQL), aur REST APIs! 💪
